# Pentesting Writeups

A structured collection of penetration-testing lab notes and technical writeups focused on understanding vulnerabilities, validating findings, and documenting practical exploitation methodology.

## Areas of Focus

* **Reconnaissance & Enumeration** — Nmap, DNS, FTP, SSH, SMB, and other network services.
* **Web Application Security** — HTTP, technologies, authentication, and common web vulnerabilities.
* **Initial Access** — Analyzing exposed services and validating attack paths in authorized labs.
* **Linux Privilege Escalation** — Permissions, SUID, cron jobs, capabilities, and misconfigurations.
* **Methodology & Lessons Learned** — Evidence-based decision-making, troubleshooting, and remediation.

## Writeup Structure

Each writeup aims to document:

1. **Lab overview** — Target environment and objective.
2. **Reconnaissance** — Host discovery and initial scan results.
3. **Enumeration** — Services, versions, and relevant observations.
4. **Analysis** — Potential attack paths and supporting evidence.
5. **Exploitation** — Steps performed in the authorized lab.
6. **Privilege escalation** — If applicable, the path and required conditions.
7. **Remediation** — Practical defensive recommendations.
8. **Lessons learned** — What worked, what did not, and why.

## Lab Scope

All practical testing documented here is intended for systems I own or have explicit authorization to assess.

## Disclaimer

These writeups are for educational purposes and defensive security learning. Techniques should only be used within authorized environments.

## Progress

Writeups will be added as labs are completed and findings are verified.
